> **Updated 22 November 2026:** channel trading lives in **akili-oto**. This repository remains the original concept and licence.

Jambo! The idea here was to buy near the bottom of a channel, sell near the top,
and repeat. **akili-oto** now covers that idea with configurable order groups and
loops, so that is the place to start.

## Get the channel strategy running

1. Open [akili-oto](https://github.com/akilibots/akili-oto).
2. Follow its Docker setup and configure your Chain testnet wallet.
3. Edit its order groups for your channel boundaries, quantities and successors.
4. Run its offline tests before trying your own configuration.

There is no executable bot or dependency installation in this repository.
The active OTO implementation uses dYdX Chain and Python 3.15.2, with durable
transitions and Docker regression tests.
