# akili-channel

This repository contains the original channel-trading concept and its licence.
There is no executable bot here.

Use [akili-oto](https://github.com/akilibots/akili-oto) for order groups that buy near
a channel's lower boundary, sell near its upper boundary, and repeat. OTO now uses
dYdX Chain, with Python 3.15.2 Docker images. Its README describes configuration,
credentials, state recovery and regression tests.
